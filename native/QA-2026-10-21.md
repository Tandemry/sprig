# Sprig 0.2.1 — bug fixes and motion QA

Native macOS app, 21 October 2026. Tested on Apple Silicon with macOS 27.0.1. This report describes the verified scope; it is not a claim that every possible bug has been eliminated.

## Fixed behaviour

| Problem | Change and evidence |
|---|---|
| Home/recent-note opening could retain the wrong board | Opening a note selects its owning board. Regression test and native UI check. |
| Switching boards/navigation could leave the previous editor or selection active | Routing dismisses the editor and clears selection. History reconciles deleted/restored records. Regression tests; editor background is disabled and hidden from accessibility. |
| Duplicating from Home could leave the copy invisible on another board | Duplicate opens its owning board and selects the copy. Regression test. |
| New empty notes opened an empty preview | New notes open in source mode with the caret focused. Regression test and native typing check. |
| Source/preview switching lost native undo and selection | Source editor stays mounted. Native check: format two lines as bullets, preview both bullets, return to source, Undo restores both original lines. |
| Formatting multiple selected lines only prefixed one line; empty caret commands inserted placeholder text | Shared UTF-16-safe formatter handles each selected line and preserves Unicode/source content. Regression tests and native multiline check. |
| Stale selection could connect notes across boards and invalidate the saved workspace | Validate endpoints and every candidate mutation before replacing working data. Regression tests. |
| Moving/recolouring notes changed Recent order | Only title/body edits update content timestamps. Regression test. |
| Parent folders omitted nested boards/notes | Descendant-aware filtering. Regression tests and native A-levels folder check. Collapsing the tree is a separate action from selecting the folder. |
| Pan did not consistently move the board when started over a note | One canvas gesture moves all notes live. Native drag check confirmed all cards move together, then Select moves only one card. Saved coordinates verified. |
| Zoom/Fit could shift the wrong point or lose distant notes | Shared anchored camera calculations and bounds-based fitting. Camera regression tests; native Fit check. New notes spawn in the visible viewport. |
| Connection hit areas could cover unrelated board space | Hit testing follows the stroked line. Note context menu can remove all its connections. Native create/remove check; persisted connection verified. |
| Search focus could be missed during the page transition | Focus is requested once the native field attaches. Native Command-K then typing filters immediately, checked with normal and reduced motion. Search trims whitespace and includes folder paths. |
| Creation sheets required extra clicking | Name receives focus. Native keyboard test created a named board using Return. Empty-folder workspaces route new-board creation through folder creation. |
| Synchronous saves could interrupt typing; overlapping instances could overwrite newer work | Serial background writer skips obsolete queued revisions, detects external changes and flushes at quit. Regression tests check newest text and external-file refusal. Save failures and import/export errors have separate reporting. |
| Header/toolbar layout and unnecessary preview/icon work | Long board titles truncate; bottom tools centre independently of side controls; Home adapts at narrow widths; previews skip unchanged renders; SVG images are cached. |

## Motion

The existing Figma colours, fonts, icon assets, reference composition and native Liquid Glass materials remain in use. No Figma file was modified.

Added spring/fade motion to page navigation, sliding navigation selection, editor presentation/dismissal, source/preview switching, note insertion/removal, colour/selection changes, board/list switching, tool selection, zoom/Fit, hover and button presses. Selection controls enter and leave smoothly. Toasts dismiss automatically. Direct dragging and panning follow the pointer without an easing delay.

Motion reads the system Reduce Motion setting. Movement, scale and hover rotation are disabled when requested. The same branch was exercised using the app-only `SPRIG_REDUCE_MOTION=1` QA override; no system setting was changed.

## Verification

- **25 Swift tests passed**, including the new navigation, formatting, camera and persistence regressions. Six original app-state problems were first reproduced by failing regression tests, then passed after the fixes.
- **1 bundled Markdown integration test passed** from a file URL, covering formatting, tables, maths and unsafe script handling without a server.
- Xcode Debug and Release builds succeeded.
- Native UI checks used a separate QA bundle identifier and disposable demo workspace: recent-note routing; new-note focus; multiline typing/formatting; preview rendering; native Undo after preview switching; note dragging; Pan over a note; connection creation/removal; parent-folder browsing/collapse; keyboard search; board creation; Fit; quit/reopen persistence; normal and reduced-motion paths.
- Final 0.2.1 ZIP checksum passed. Extracted app version was 0.2.1 and its ad-hoc signature passed strict verification outside the File Provider-managed Documents folder.
- The real workspace checksum was unchanged after testing. Previous 0.2.0 app and ZIP were retained.

## Limits

Physical trackpad pinch/momentum and every possible window size were not hardware-tested; anchored zoom and fit maths are covered by tests. The editor still switches between full source and full preview. Mixed inline editing, note resizing, moving boards between folders, sync and automatic updating remain future work. This is a local ad-hoc-signed Apple Silicon build, not a notarised or GitHub-published release.
